NearU

Find a friend with Bluetooth signal strength. Two phones, the same temporary code, both apps in front. This page only hands you the install file.

Download NearU

The file is NearU-0.2.0.apk, about 9 MB. Install that file. Do not unzip it. If a file manager opens folders named META-INF or classes.dex, that is the wrong move. Delete those and tap the APK. Android 8 or newer. Allow install from the browser if Android asks.

On both phones

  1. Turn Bluetooth on. For the first try, turn Location services on too. The app does not store GPS.
  2. Allow Nearby devices. That is Bluetooth permission. Camera is asked only if you scan a QR.
  3. Keep NearU in front. Leaving the app stops discovery on purpose.
  4. One phone: Find a friend. The other: Join, then scan the QR or type the code.
  5. Walk apart, then back. The bar is strength, not a direction. A short silence says Holding last reading. Signal lost takes about 8 seconds.

Not in this build

  • No iPhone build.
  • No map, arrow, compass, or route.
  • No use of other people's phones.
  • No background tracking, account, or saved place.

Source and the signal rules are in the repository. Diagnostics inside the app should say NearU POC 0.2.0.
